# Settings

Everything you can configure in Namida, in the same order as the in-app settings page.

::: callout info
Some settings only work on specific platforms or Android versions. They are labeled like `💻 Android 12+ only`.
What iOS and macOS don't have yet is listed in [Installation](/installation/#ios-macos) instead.
:::

::: callout tip
Use the Search button in Namida settings to quickly find any setting. It matches the options inside settings too (like an effect or a performance mode).
Results show where each option exists, tap one to jump right to it, or flip a switch without leaving the results. The "Changed" chip lists every setting you changed, each with a reset button. `🆕 v8.2.0`
:::

::: callout tip
Moving some sliders to the very start or end turns the option always on or always off (like Always or Never).
:::

### Quick Tiles {#quick-tiles}

The tiles at the top of the settings page are shortcuts (Add Folder / Refresh Library / [Sync](/features/sync/) / [Listening party](/features/party/) / [Sleep timer](/features/playback/#sleep-timer) / [Sound Control](/features/playback/#sound-control)). The sleep timer tile shows what's left while it runs. `🆕 v7.4.0`

### Settings Icon {#settings-icon}

The settings icon at the top of the app can show a few small signs:

- **Radar icon**, this device is running a Sync server, so other devices can find it. Keeping it running might use more battery.
- **Green dot** (top right), a device is connected through Sync.
- **Ring around the icon**, Sync is sending or receiving data. It fills up as the transfer goes. `🆕 v8.5.0`
- **Purple dot** (bottom left), your Discord status is showing what you're listening to.

The settings tiles show the same signs, so you can find where each one comes from. The Extras tile shows the purple dot, and the Backup & Restore tile shows the Sync signs. The Sync quick tile and the Sync tile (inside Backup & Restore) also show a gray dot when a device that connected earlier got disconnected.
