# Shortcuts

`💻 Windows+Linux only`

Control Namida from the keyboard on desktop.

### Playback {#playback}

| Shortcut | Action |
| --- | --- |
| `Space` | Play / Pause |
| `←` / `→` | Seek backwards / forwards |
| `Ctrl` + `←` / `→` | Previous / Next track |
| `Shift` + `←` / `→` | Previous / Next chapter `🆕 v8.2.0` |
| `Ctrl` + `↑` / `↓` | Volume up / down |
| `Ctrl` + `Space` | Stop after this track `🆕 v8.2.0` |
| `Ctrl` + `Tab` | Change repeat mode |
| `Ctrl` + `Shift` + `S` | Shuffle, following the shuffle button mode `🆕 v8.4.0` |

Seeking jumps by your [Seek Duration](/settings/3-playback-settings/#seek-duration).
Shuffle follows the mode of the shuffle button (toggle / Shuffle Next / Shuffle All). [`🎉 Queue System ↗`](/features/playback/#queue)

### Zoom {#zoom}

`🆕 v7.1.0`

| Shortcut | Action |
| --- | --- |
| `Ctrl` + mouse wheel | Zoom in / out |
| `Ctrl` + `+` / `-` | Zoom in / out |
| `Ctrl` + `0` | Reset the zoom |

Zoom applies to what is in front of you: the lyrics font size, or the card size in a playlist download page. It is the desktop version of the pinch gesture.
The lyrics size can also be set from the [lyrics picker](/features/playback/#lyrics-picker).

### Current Track {#current-track}

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `H` | Add / remove favourite |
| `Ctrl` + `B` | Add bookmark `🆕 v8.2.0` |
| `Ctrl` + `L` | Toggle lyrics |
| `Ctrl` + `Shift` + `L` | Lyrics fullscreen |
| `Ctrl` + `Alt` + `1..9` | Set rating, 10% to 90% |

::: callout info
Setting a rating writes it to the file tags of the current track.
:::

### Navigation {#navigation}

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `E` | Expand / collapse miniplayer |
| `Ctrl` + `Q` | Open queue |
| `Ctrl` + `F` | Search, or settings search while in settings |
| `Ctrl` + `Shift` + `P` | Open settings search |
| `Ctrl` + `1..9` | Jump to library tab |
| `Ctrl` + `R` | Refresh library |
| `Ctrl` + `Alt` + `L` | Mini lyrics window `🆕 v7.0.0` |
| `F11` | Fullscreen |
| `Esc` | Go back, or leave the mini lyrics window |

After pressing `Tab`, the arrow keys move between items instead, and `Esc` leaves them. `🆕 v8.4.0`
The mini lyrics window is a small window with the current lyrics line, see [`🎉 System Integration ↗`](/features/system-integration/#mini-lyrics).
In the fullscreen artwork viewer, `←` / `→` switch between images. `🆕 v8.2.0`

### Lyrics Editor {#lyrics-editor}

`🆕 v8.2.0`

The lyrics editor has its own shortcuts for syncing, see [`🎉 Lyrics Editor Shortcuts ↗`](/features/lyrics-editor/#shortcuts).

### Custom Hotkeys {#custom-hotkeys}

The shortcuts above only work while Namida is focused, and all of them are listed in the shortcuts dialog (press the shortcut icon in the title bar, or go to Settings -> About -> Shortcuts). It groups them in cards, with a search field. `🆕 v8.4.0`

For system wide hotkeys, press the globe button beside play/pause, next/previous, seek, volume or stop after this track `🆕 v8.2.0`, then press your keys right there. `🆕 v8.4.0`

- Keys already used by another shortcut, or keys that type text (like a plain letter), show a warning and can't be saved.
- If the system refuses the hotkey (like when another app uses it), the error shows and the old one is kept.
